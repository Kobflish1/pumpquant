Test periods

Each period tests the best version of the rule on tokens that launched after the ones it learned from. Select a period to see its trades.

How it’s tested

Learn from the past, test on the future

The same four steps repeat, moving forward in time. A token is never split across the line, so a test can’t learn a token’s later life, and every period counts fees, failed orders and positions still open at the end.

  1. 1Try 16 versions of the momentum rule on all earlier tokens.
  2. 2Keep the best one, chosen only from those earlier results.
  3. 3Test it on the next 6 tokens, which it has never seen, with real delays and costs.
  4. 4Move forward and repeat for the next period.

Drawn to scale from this demo run: 36 simulated tokens in launch order.

Limits

What this demo shows, and what it doesn’t

It shows

  • The full method running end to end: generate data, search, test, replay.
  • Every test uses only data from after the period it learned on.
  • Fees, failed orders and unfinished positions are counted, not dropped.

It doesn’t show

  • Real market data. Every price here is simulated.
  • That the rule makes money. Three simulated tests are far too few to say.
  • Live trading. Nothing is connected to a market or a wallet.
